# nontk — Steal An Egg Script (Thai UI)

โคลนสคริปต์ Steal An Egg แบบเต็มระบบ UI ภาษาไทย ธีมส้ม ไม่มีการขอ key ไม่ผูกกับเว็บผู้พัฒนาเดิม

## วิธีใช้ (บนเครื่องไหนก็ได้)

เปิดเกม **Steal An Egg** บน Roblox → เปิด executor → รันสคริปต์โหลดเตอร์ 1 บรรทัด:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ชื่อผู้ใช้/ชื่อrepo/main/NONTK_Clone_Thai.lua"))()
```

> เปลี่ยน `ชื่อrepo` เป็น repo ที่มึงอัพโหลด (เช่น `user/nontk-sae`)

หรือถ้าอยากรันจากไฟล์ในเครื่องโดยตรง: เปิด executor → เลือกไฟล์ `NONTK_Clone_Thai.lua` → Execute

## ข้อจำกัด

- รองรับเฉพาะเกม **Steal An Egg** (GameId `10563114921`)
- ฟีเจอร์มอนิเตอร์แดชบอร์ดบางส่วนเดิมพึ่งเซิร์ฟเวอร์ของผู้พัฒนาเดิม — ปุ่มจะกดได้แต่ถ้าเบ็คเอนด์มันปิด มันจะไม่มีข้อมูลมาโชว์ (ส่วนอื่นใช้ได้ปกติ)
